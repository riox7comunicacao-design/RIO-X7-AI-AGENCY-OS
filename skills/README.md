# Skills — Referência

As Skills operacionais oficiais da Rio X7 são **nativas do Notion**. O Notion é a fonte de verdade dessas Skills — não este repositório. Este arquivo apenas registra que elas existem e documenta os limites do que o projeto local pode conter sobre elas.

## Skills existentes no Notion

1. **RIO X7 SDR — Psicologia**
2. **RIO X7 Raio-X Engine — Universal**

Confirmadas como Skills nativas reais do Notion (não apenas páginas com nome de Skill) em auditoria realizada em 2026-09-16.

## O que o projeto local NÃO deve manter

O projeto local **não deve manter uma cópia integral** do conteúdo dessas Skills, nem uma segunda versão independente. Duas cópias completas do mesmo conteúdo divergem com o tempo — o Notion é onde a Skill é escrita, mantida e evolui.

## O que o projeto local PODE manter

- Referências (como este arquivo).
- Documentação de integração com as Skills.
- Testes relacionados ao uso das Skills.
- Adaptadores de execução, se e quando necessários.
- Documentação técnica de apoio.

## Execução de Skill fora do Notion

Se, no futuro, houver necessidade real de executar uma Skill fora do Notion (por exemplo, por uma automação local), isso não deve acontecer por cópia manual do conteúdo. Essa necessidade deve primeiro ser registrada e decidida em uma decisão arquitetural específica (ver [docs/decisions/](../docs/decisions/)), para manter uma única fonte de verdade.
